# 🍽️ Zomato Sales Analysis Dashboard | Power BI

## 📌 Project Overview
The Zomato Sales Analysis project is an interactive Power BI dashboard designed to analyze restaurant sales performance, customer preferences, ratings, and order trends. It provides meaningful business insights through interactive visualizations and KPIs.

## 🎯 Project Objectives
- Analyze overall restaurant sales performance.
- Track total revenue and orders.
- Understand customer preferences.
- Identify top-performing restaurants.
- Analyze customer ratings and reviews.
- Evaluate sales trends across different locations.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Excel** – Data preparation and analysis.

## 📊 Dashboard Features
- Total Sales Analysis
- Total Orders
- Average Order Value
- Restaurant Performance
- Customer Rating Analysis
- City-wise Sales Analysis
- Cuisine-wise Sales Distribution
- Online vs Offline Orders
- Monthly and Yearly Sales Trends

## 📈 Key Insights
- Identified high-performing restaurants.
- Analyzed customer ratings and preferences.
- Evaluated sales performance across locations.
- Compared different cuisines based on sales.
- Identified ordering patterns and business trends.
  
## 🚀 Skills Demonstrated
- Data Cleaning
- Data Transformation
- Data Modeling

## 💡 Conclusion
This project demonstrates how Power BI can transform raw restaurant data into meaningful business insights. The interactive dashboard helps analyze sales performance, customer behavior, restaurant ratings, and business trends to support better decision-making.
